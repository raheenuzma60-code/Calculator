# 🧮 Calculator – Python

A simple **command-line calculator built using Python** that performs basic arithmetic operations based on the user's input.

This project is part of my Python learning journey and was created to practice functions, user input, conditional statements, and basic error handling.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚠️ Handles division by zero
- ❌ Handles invalid operators
- 🧩 Uses separate functions for each arithmetic operation

## 🛠️ Concepts Used

- Python Functions
- User Input using `input()`
- `float()` for numerical input
- `if-elif-else` statements
- Arithmetic Operators
- Function Calling
- Basic Error Handling
- String Input Validation

## 💻 How It Works

The program asks the user to enter:

1. The first number
2. The operator (`+`, `-`, `*`, `/`)
3. The second number

Based on the operator entered, the corresponding function is called and the result is displayed.

### Available Operations

| Operator | Operation |
|----------|-----------|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
